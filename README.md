# Портфолио Артёма Бажутина

Портфолио графического и моушен-дизайнера. Главная страница содержит обложку,
биографию, опыт и услуги; проекты Reloc и FunPay оформлены как отдельные кейсы
с собственными страницами и подборками работ на Vimeo.

## Разработка

```bash
npm install
npm run dev
```

Проверка перед публикацией:

```bash
npm test
```

Основной контент находится в `app/page.tsx`, стили — в `app/globals.css`.
Визуальные заглушки кейсов позже будут заменены реальными изображениями и видео.
